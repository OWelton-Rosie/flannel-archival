# Contributing to the project
This guide will give users who aren't familiar with Git and GitHub instructions on editing the project. If you're an experienced Git/GiHub user, skip [https://github.com/OWelton-Rosie/flannel-archival/CONTRIBUTING.md#for-the-nerds]()

## Prerequisites
Before contributing, you will need a GitHub account. If you don't have one, [click here](https://github.com/signup).

## Project structure
The project stores all past flannels in PDF format in [`/static/assets/pdfs/`](https://github.com/OWelton-Rosie/flannel-archival/tree/main/static/assets/pdfs). This is the only folder you should need to edit.

## Update workflow
_(The following steps will be explained in detail.)_
- Fork the repo
- Commit to the `staging` branch
- Verify that it works on the staging site
- Send a pull request to the `main` branch
- Wait for a maintainer ([Oscar](https://github.com/OWelton-Rosie)) to review the pull request
- Either merge the pull request, or ask Oscar to merge it
- Update your fork

Select the "fork" button:
